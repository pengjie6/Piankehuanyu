## 15:35 修复抖音构建报错 Incompatible color space with graphics API
- 根因：工程 Color Space = Linear（m_ActiveColorSpace: 1），但 WebGL 图形 API 被固定成 WebGL 1.0（`m_APIs: 08000000`=OpenGLES2, `m_Automatic: 0`）。Linear 只能配 WebGL 2.0；WebGL1 必须 Gamma。TTSDK Builder.BuildWebGL 构建前校验直接报错。
- 对照：`_Backup_20261125_1440` 里该段是 `m_APIs: 0b000000`(OpenGLES3/WebGL2) + `m_Automatic: 1`，即被改过。
- 处理（走 WebGL2 路线，保持画面不变）：ProjectSettings.asset WebGLSupport → `m_APIs: 0b000000` + `m_Automatic: 1`；`Assets/Editor/StarkBuilderSetting.asset` → `isWebGL2: 1`（SDK 构建前会 SetGraphicsAPIs，由该开关决定用 GLES3 还是 GLES2）。
- 备选（未采用）：Color Space 改 Gamma + 保持 WebGL1，兼容性最好但整画面变亮，需重调配色。
- 备份：`_Backup_20261125_1532/`（ProjectSettings.asset、GraphicsSettings.asset、StarkBuilderSetting.asset）。
- 注意：Unity 编辑器当时正在运行，设置需重导入/重启才生效；若退出时被内存值覆盖，需在 Player Settings 手动勾 Auto Graphics API。
