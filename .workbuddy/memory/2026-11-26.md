## 修复 StarkBuilder 构建失败（DirectoryNotFoundException）

**现象**：点 Stark SDK 面板 Build，报
`Create directory E:\unitystudy\project\Unity2022_拥堵突围计划_TrafficJamEscape\...\Unity2022_拥堵突围计划_TrafficJamEscape failed: DirectoryNotFoundException`

**根因**：工程从 E 盘整目录搬迁到 `D:\unitystudy\project\拥堵突围计划`，但
`Assets/Editor/StarkBuilderSetting.asset` 里保存的三处绝对路径仍是旧机器/旧盘，
且构建输出路径被重复叠加了 3 层项目名。本机只有 C、D 两个盘，E 盘不存在，
`Directory.CreateDirectory` 无法凭空创建盘符 → 抛异常。

**修改**（文件：`Assets/Editor/StarkBuilderSetting.asset`）：
- `OutputDir`：`E:\...\Unity2022_...\Unity2022_...\Unity2022_...\tt-minigame`
  → `D:\unitystudy\project\拥堵突围计划\Build\tt-minigame`
- `_webglPackagePath`：同步改为 `...\Build\tt-minigame\tt-minigame`（保持 OutputDir+\tt-minigame 结构）
- `idePath`：`E:/douyinDeveloper/...` → `D:/TikTok_Developer/@bytedminiprogram-ide/抖音开发者工具.exe`（实测存在）

**顺带消除的告警**：
- `Google.IOSResolver.dll` 报 `Unable to resolve reference 'UnityEditor.iOS.Extensions.Xcode'`：
  未安装 iOS Build Support 模块所致，对抖音小游戏无影响。
  已在 `Assets/ExternalDependencyManager/Editor/1.2.177/Google.IOSResolver.dll.meta` 把
  `validateReferences: 1` → `0`（等同 Plugin Inspector 取消 Validate References）。
- `AssetDatabase.FindAssets: Folder not found: 'Assets/ByteGame'`：bgdt 插件搜索路径写死，
  实际目录是 `Assets/Plugins/ByteGame`，纯告警，不影响构建，未处理。

**环境事实**（后续会用到）：
- 工程根：`D:\unitystudy\project\拥堵突围计划`
- Unity 引擎：`D:\unitystudy\engine\2022.3.62f3c1`（Unity 2022.3.62f3c1）
- 抖音开发者工具：`D:\TikTok_Developer\@bytedminiprogram-ide\抖音开发者工具.exe`
- 抖音小游戏 appId：`tt1ede686380a0448002`（写在 StarkBuilderSetting._appId）
- `.gitignore` 已忽略 `/Build/`、`/tt-minigame/`，构建产物不进版本库
- 旧配置备份：`_Backup_20261126/StarkBuilderSetting.asset.bak`
